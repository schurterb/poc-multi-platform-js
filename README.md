# Proof-of-concept Multi-plaform Javascript usage (with WASM)

### Overview

This is a simple framework demonstrating one way to use Javascript ES Modules 
seemlessly (i.e. no changes to the module code) on both the server and client side.
I put this together as an experiment and proof-of-concept (hence the name) to
see if I wanted to use it in a larger project. 
There are two examples in here:
 1. "getIP" uses the `axios` module to call a web endpoint.

Both of these examples work for me.  That doesn't necessarily mean they'll work for you,
but at the very least, this can get you started.
